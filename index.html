Accompagnement jazz : basse + batterie

Syntaxe Accords séparés par des espaces : Cm7 F7 = 2 accords dans la mesure. % répète la mesure précédente. Position explicite : Cm7[1] F7[2.5] (temps à partir de 1). Basse : C/E (basse pédale). Exemples d'accords : Cmaj7 Dm7 G7 Bb7#11 Am7b5 E7b9 C13 Dm9 Gsus.
